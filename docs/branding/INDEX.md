## 🚀 Como Usar

### **Para Web (Imediato)**
```html
<!-- Header/Navbar -->
<img src="/assets/logos/circuit-community/horizontal.svg" height="60px" />

<!-- Favicon -->
<link rel="icon" href="/assets/logos/circuit-community/favicon.png" />

<!-- Dark Mode -->
<img src="/assets/logos/circuit-community/dark-bg.svg" class="dark-mode" />
```

### **Para Social Media**
- Perfil: Use `square.png` (1024×1024px)
- Banner: Use `horizontal.png` (1920×640px)
- Favicon: Use `favicon.png` (512×512px)

### **Para Print**
- Letterhead: Use `horizontal.svg`
- Monocromática: Use `monochrome.svg`
- Tamanho mínimo: 15mm
