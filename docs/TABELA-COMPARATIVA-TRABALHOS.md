## 4. Tendências Identificadas

### 4.1 No Mercado (Plataformas)
- **Automação de projetos** com IA (Rabbit): demanda crescente
- **Desafios criativos** com impacto social (Manual Maker): modelo escalável
- **Gamificação** e prêmios: motivador comprovado

### 4.2 Na Academia (Artigos)
- **RAG em IoT** é campo emergente (2024-2026)
- **Federated RAG** para ambientes com recursos limitados
- **Agentic RAG** como padrão de orquestração inteligente
- **Privacy-by-design** (LGPD, federated learning)
- **Real-time processing** com edge computing

### 4.3 Convergência para MakerConnect
1. **Rabbit Agents pattern** → n8n + MakerBrain (orquestração)
2. **Manual Maker pattern** → Gamificação + Desafios de governança IoT
3. **Academic insights** → RAG + Federated + Edge para documentação técnica
