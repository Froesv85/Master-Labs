## 2. TESTAR EXTRACTION (PowerShell)

```powershell
$body = @{
    input = "Arduino Mega 2560 com sensores BMP180, DHT11 e MQ135. Comunicacao via USB serial em 115200 baud. Problema: crashes aleatorios a cada 12 horas. Solucao: reduzir frequency de amostragem de 10Hz para 5Hz."
    source = "manual"
} | ConvertTo-Json

$response = Invoke-RestMethod -Uri "http://localhost:3000/api/projects/1/extract" `
    -Method Post `
    -Headers @{"Content-Type" = "application/json"} `
    -Body $body

$response | ConvertTo-Json -Depth 10
```

Copie e execute. Resultado deve conter:
- logId
- webhookId
- status: "queued"
- embeddingId

## 3. CONSULTAR LOGS

```powershell
Invoke-RestMethod -Uri "http://localhost:3000/api/projects/1/extract" `
    -Method Get | ConvertTo-Json -Depth 10
```

Deve listar todos os logs de extracao do projeto 1.
Status deve passar de "queued" → "done" após n8n processar.

## 4. SIMULAR CALLBACK (se n8n não responder)

Use o webhookId do resultado do comando #2:

```powershell
$callbackBody = @{
    webhookId = "COLE_AQUI_O_WEBHOOKID_DO_TESTE_2"
    status = "done"
    n8nExecutionId = "exec_12345"
    latencyMs = 250
    output = @{
        relevance = 0.87
        keywords_found = 5
        processing_time = "234ms"
    }
} | ConvertTo-Json -Depth 5

Invoke-RestMethod -Uri "http://localhost:3000/api/projects/1/extract/callback" `
    -Method Post `
    -Headers @{"Content-Type" = "application/json"} `
    -Body $callbackBody | ConvertTo-Json -Depth 10
```

Após isso, execute comando #3 novamente - status deve estar "done".

## 5. TESTAR ERROR HANDLING

## Fluxo Esperado

```
POST /api/projects/1/extract
    ↓
Cria log (status: queued)
    ↓
Dispara webhook → n8n
    ↓
n8n processa
    ↓
n8n chama POST /api/projects/1/extract/callback
    ↓
Atualiza log (status: done)
    ↓
GET /api/projects/1/extract mostra resultado com latencyMs + output
```
